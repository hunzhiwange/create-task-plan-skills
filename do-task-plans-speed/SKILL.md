# 快速执行任务计划

1. 在当前会话使用当前模型直接执行。读取指定任务文件、其中引用的公共计划以及仓库约定，按任务范围实现代码和必要接线，并编写覆盖本次变更的单元测试。
2. 本轮只做代码实施和单元测试编写。Rust 项目不运行 Cargo 验证，包括通过脚本或命令别名间接触发的 Cargo 检查、编译和测试。所有任务均不运行单元测试，也不做任务实机测试。将这些验证留待之后统一执行。
3. 核对实现和单元测试是否已写齐，写完立即删除本次执行的任务文件。保留公共计划和其他任务文件。实施受阻或尚未写完时保留任务文件。
4. 交接时简述已实现的内容，并注明验证留待统一执行。
